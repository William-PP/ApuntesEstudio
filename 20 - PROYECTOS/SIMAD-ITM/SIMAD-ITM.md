# SIMAD-ITM

> [!info] Sistema integral del Instituto Tecnológico Metropolitano de Medellín
> SIMAD-ITM es el sistema de información integral del ITM. Su módulo deportivo — **GestionDeportiva** — es el foco actual de documentación, y comparte con este proyecto la misma base documental (narrativa de requisitos y diccionario de entidades).

## Objetivo

Proveer al ITM una plataforma centralizada que elimine la fragmentación de datos (papel, hojas de cálculo, memoria de entrenadores) y garantice trazabilidad, auditoría y cumplimiento legal (Ley 1581 de Protección de Datos Personales).
